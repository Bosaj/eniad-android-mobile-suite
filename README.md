# 📱 ENIAD Android Native Mobile Suite

Native Android mobile application architecture developed for the **Développement d'Application Mobile** module (Semestre 7) at **ENIAD**.

---

## 🎯 Features & Architecture
- **Multilingual Support**: Fully localized resource bundles in **Arabic (`values-ar`)**, **English (`values-en`)**, and **French** with automatic RTL (Right-to-Left) mirroring.
- **Material Design UI**: Custom themes, adaptive vector drawables (`mipmap-anydpi-v26`), and night/dark mode styling.
- **Core Activity Lifecycle**: `ActivatePrincipale.java` managing intent dispatch, user state persistence, and activity lifecycle hooks.
- **Modern Build Architecture**: Kotlin DSL Gradle build scripts (`build.gradle.kts`, `settings.gradle.kts`).

## 🛠️ Tech Stack
- **Android Studio Ladybug / Koala**
- **Java 17**, **Android SDK 34+**, **Kotlin DSL Gradle**
- **XML Layouts**, **Material Components for Android**
